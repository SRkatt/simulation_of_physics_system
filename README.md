# Simulation of Physical System

Авторы: Назаров Егор, Сурконт Виктор

## Описание проекта

Проект представляет собой симулятор системы связанных осцилляторов: масс, соединённых пружинами.

Программа позволяет настраивать параметры физической системы, запускать моделирование и наблюдать поведение модели во времени. В проекте реализованы численные методы расчёта движения, визуализация системы масс и пружин, а также отображение графика энергии.

Модель демонстрирует основные свойства колебательных систем:

- сохранение полной механической энергии в системе без демпфирования;
- спад энергии при наличии вязкого демпфирования;
- устойчивое поведение системы в интерактивном режиме.

## Основные возможности

- моделирование системы масс и пружин;
- настройка параметров системы: массы, жёсткости пружин, демпфирования и начальных положений;
- запуск, пауза и сброс симуляции;
- выбор численного метода интегрирования;
- визуализация движения системы;
- отображение графика энергии;
- сохранение и загрузка параметров в формате JSON.

## Используемые технологии

Проект написан на C++ и собирается с помощью CMake.

Основные технологии:

- C++17;
- CMake;
- SFML;
- ImGui;
- ImGui-SFML;
- nlohmann/json.

## Зависимости

Для сборки проекта необходимы:

- компилятор с поддержкой C++17;
- CMake версии 3.16 или выше;
- SFML;
- ImGui;
- ImGui-SFML;
- nlohmann/json.

Если зависимости подключены через `CMakeLists.txt`, CMake автоматически загрузит или подключит необходимые библиотеки при конфигурации проекта.
